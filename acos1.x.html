AC OS 0.1.1a "Longhorn" — Help and Support

      
What's in this build

      
    
        
  • Setup — first-run installer with license, user account, optional password and theme; it only runs once (Control Panel → AC OS Setup can run it again).
    • 
        
  • Aero glass + themes — Aero, Plex, Slate and Jade, adjustable glass blur, wallpapers, solid colors or your own picture.
    • 
        
  • Flip 3D — press Alt+Q or the ⧉ button on the taskbar; scroll or use arrow keys, click or Enter to pick.
    • 
        
  • Taskbar thumbnails — hover a taskbar button for a live preview of game and emulator windows.
    • 
        
  • Sidebar and gadgets — Clock, Slide Show, CPU Meter, Notes, Now Playing and Calendar; add or remove them from the Gadgets gallery.
    • 
        
  • Documents (ACFS) — WinFS-style storage: virtual folders by type and tag, full-text search, preview pane, Recycle Bin.
    • 
        
  • Desktop search — the Start menu search finds programs and documents.
    • 
        
  • AC Shell (MSH) — a command shell with Monad-style verbs: get-childitem, get-process, start-process…
    • 
        
  • Apps — Web Explorer with tabs, Media Player with visualizer, Photo Gallery with slide show, Paint, Calculator, Minesweeper, Task Manager, Run, Control Panel, plus everything from 0.1.1.
    •
